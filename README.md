# Willkommen! Ich bin Josef.

Ich entwickle praktische Programme für Linux Mint. Meine Projekte entstehen aus Aufgaben, die mir im täglichen Umgang mit dem Rechner begegnen: Welche Hardware steckt im PC? Wie lassen sich Programmeinstellungen sichern? Welche Geräte befinden sich im Netzwerk? Wie kann ich eine Webseite auf Fehler prüfen – oder meine OBSBOT Tiny 2 am Linux-Rechner steuern?

Daraus entwickle ich Werkzeuge mit grafischer Oberfläche, verständlichen Einstellungen und übersichtlichen Ausgaben. Ich arbeite hauptsächlich mit Python und lege Wert darauf, dass sich die Programme gut unter Linux Mint mit Cinnamon bedienen lassen.

**Deutsch und Englisch gehören zur Grundausstattung. Acht weitere Sprachen mit Offline-Hilfe sind je nach Projekt direkt enthalten oder als Zusatzpakete verfügbar.**

## Ausprobieren, prüfen, verbessern

Ich entwickle und prüfe die Programme selbst. Trotzdem kann ich etwas übersehen – gerade weil ich weiß, wie ich mein eigenes Programm bediene. Rückmeldungen aus der praktischen Nutzung helfen deshalb besonders.

Wenn du einen Fehler findest, öffne bitte im betreffenden Projekt ein Issue, sofern die Funktion dort aktiviert ist. Alternativ erreichst du mich über die Kontaktseite auf meiner Webseite. Hilfreich sind:

- Programmversion und Linux-Mint-Version.
- Was du machen wolltest und welche Schritte zum Problem geführt haben.
- Was du erwartet hast und was stattdessen passiert ist.
- Die genaue Fehlermeldung oder ein Screenshot ohne persönliche Daten.

Verbesserungsvorschläge und Hinweise zur Verständlichkeit der Oberfläche sind ebenfalls willkommen.

## Welcome! I'm Josef.

I develop practical applications for Linux Mint, with a focus on graphical interfaces, clear settings and useful reports. My projects cover hardware information, configuration backups, local network devices, website checks, PDF tools and camera control for the OBSBOT Tiny 2.

**German and English are included by default. Eight additional languages with offline help are available in the current source or as separate language packs, depending on the project.**

Verified on November 5, 2026: the published DEB packages currently include German and English. Tiny, mintpdf and PCMonitor now include ten languages with help in the current source, but not yet in the linked DEBs. PCMonitor’s eight additional packs are also complete with 328 strings each. 6aus45 has source code and ten languages with help, but no published DEB release. Additional translations are machine-generated and still need native-language review. Please check each repository for its current features, requirements and development status.

Bug reports, ideas and feedback are welcome. Please include the application version, your Linux Mint version, steps to reproduce the issue and any relevant error messages. Remove personal information from logs and screenshots before sharing them.
